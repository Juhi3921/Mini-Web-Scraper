# Mini Web Scraper

A beginner friendly web scraper built using Python, Flask, 
BeautifulSoup, HTML, CSS and JavaScript.

## Features

- Scrape a webpage
- Extract page title
- Extract headings
- Extract links
- Extract images
- Extract paragraph text
- Show HTTP status
- Show response time
- Preview scraped images
- Download results as TXT
- Download results as JSON

## Technologies Used

- Python
- Flask
- Requests
- BeautifulSoup
- HTML
- CSS
- JavaScript
